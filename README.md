# BLOXITY — revival build

Independent Roblox-2017-inspired revival project. This is not Roblox and does not include Roblox proprietary client binaries, code, or assets.

## Included in this build

- Classic-style BLOXITY website shell, mobile responsive.
- Existing username/password Supabase Auth flow and player profiles.
- Player IDs generated by the database. The first account created in this currently empty project receives ID 1.
- Root admin model: player ID 1 is the owner; only ID 1 can grant/revoke additional admin permissions. Admin currency adjustments are protected by server-side checks.
- Robux and Tix balances stored server-side, with transaction history; Tix daily claim (+10 every 24 hours) and multi-currency catalog purchase support.
- Free Builders Club, Turbo Builders Club, and Outrageous Builders Club selection; one tier per account, each with its own catalog hat and 85 Robux per 24 hours.
- BloxCoins daily reward and catalog purchase RPCs.
- Starter Gear catalog entries (Gravity Coil, Speed Coil, Paint Bucket, Classic Radio) for future integration into compatible BLOXITY experiences.
- Additive Supabase migration: `20261117_bloxity_revive_core.sql`.

## Supabase

The migration was applied to the connected `Bloxity` Supabase project. It preserves the existing profiles, friend requests, catalog, inventory, and BloxCoins tables. RLS remains enabled on the new exposed tables. Never put a service-role key in `config.js`.

The project had zero profiles when this migration was applied. Therefore, the first person to register will receive player ID 1 and become the root owner. Do not open public registration before the owner account is created and secured.

## Not yet implemented / not production-ready

This build is a foundation, not a complete Roblox 2017 clone. The actual R6/R15 runtime, Gear behavior inside games, Tix earning/exchange rules, Limited serial-number economy, trading, messaging, groups, moderation workflows, user-created game publishing, authoritative multiplayer game servers, and native Android/Windows player clients still need implementation and testing. The current game cards remain previews. Do not advertise multiplayer or downloadable clients as available yet.

The Gear catalog entries are definitions only; the game runtime must enforce their effects and permissions. Builders Club hats are catalog entitlements with simple placeholder artwork until original BLOXITY hat assets are added.

## Local testing

Open `index.html` through a local web server or static hosting. The Supabase URL and publishable key are in `config.js`. Authentication must have email confirmation configured consistently with the project's username-only alias approach. Do not share passwords or database secrets.
