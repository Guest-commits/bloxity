# BLOXITY — Starter web

Prototipo inicial bilingüe (español/inglés) con estética inspirada en 2017.

## Archivos
- `index.html`: estructura de la página.
- `style.css`: estilos adaptables a móvil.
- `script.js`: selector de idioma.
- `assets/logo.png`: concepto de logo.

## Probar en Android
Abre `index.html` desde un editor/visor HTML local o súbelo a un alojamiento estático de pruebas.

## Importante
Este starter es solo la interfaz visual. Los botones de registro e inicio de sesión todavía no autentican usuarios. Antes de abrir el proyecto al público habrá que conectar un backend seguro, validar sesiones y proteger datos. BLOXITY es un proyecto independiente y no incluye código ni servicios internos de Roblox.
