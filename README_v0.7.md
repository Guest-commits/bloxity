# BLOXITY v0.7 — Economía y BloxCoins

1. Extrae el ZIP completo.
2. Conserva tu configuración Supabase en `config.js`.
3. Ejecuta en Supabase SQL Editor las migraciones en el orden indicado en `SETUP_v0.3.md`.
4. Publica la carpeta en hosting HTTPS.
5. Registra o inicia sesión: cada cuenta recibe 500 BloxCoins.

Incluye recompensa diaria (+100 cada 24 horas), compras de catálogo, inventario e historial.
Las operaciones monetarias se ejecutan en PostgreSQL mediante RPC protegidas.
BloxCoins es ficticia y no está conectada a Roblox ni a Robux.
